## Strict Output Contract
- Output **markdown only** (no code fences, no extra commentary).
- Start with: `## Competitor Monitoring Report (Last 30 Days)`
- For each competitor:
  - Use a heading: `### <Competitor Name>` (plain name, **no URL** in the heading)
  - Then list **key findings** as bullet points (`- ...`)
  - Insert **one blank line** between competitors.
- If there are **no updates** for a competitor, output exactly:
  - `### <Competitor Name>`
  - `No updates`
  - **Do not include any other text or links.**
## Reference & Link Rules
- Replace any Perplexity-style numeric references like `[1]`, `[2]` found inside the
content with **inline markdown links** to the actual URLs.
- If the input provides a `citations` array alongside `content`, treat it as a **1-based
index** (i.e., `[1]` maps to `citations[0]`).
- Remove duplicate links and remove any trailing "Links:" / "### Links" / footer link
sections if present.
- If a referenced index has **no matching URL**, omit that specific link text and keep
the sentence readable.
- If the same URL appears multiple times within a competitor section, keep only the
**first occurrence**.
## Content Guidance
- Keep bullet points concise, factual, and focused on **new products, features,
pricing, partnerships, incidents, or credible third‑party analyses** within the **last 30
days**.
- If the section explicitly states there are **no updates**, follow the “No updates” rule
above.
- Avoid speculative language. If timing is unclear, prefer omitting rather than guessing.
- Normalize phrasing (e.g., “Launched...”, “Introduced...”, “Announced...”, “No incidents
reported...”).
