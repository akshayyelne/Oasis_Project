> **I rewrote my mental health agent from an autonomous swarm to a deterministic state graph. Here's why that wasn't a technical preference — it was a safety requirement.**
>
> The original version used AutoGen Swarm: agents handing off to each other implicitly, deciding among themselves what happens next.
>
> That's elegant. In a mental health context, it's also unacceptable.
>
> If a user types something indicating crisis, "the agents will probably route it correctly" is not an answer you can give a clinician, a regulator, or a family member.
>
> So I migrated the whole thing to **LangGraph StateGraph**:
>
> → **Typed state (Pydantic)** — deterministic data flow, not free-form message passing
> → **Explicit graph edges** — every possible path is declared, not emergent
> → **A safety router node** — crisis detection sits *before* assessment and action nodes. If it fires, the graph returns a crisis response and the downstream agents never run.
> → **An MCP tool server** — three tools: `calculate_wellness_score`, `get_coping_techniques`, `lookup_crisis_resources`. The wellness score is *computed*, not hallucinated by an LLM.
> → **Optional Postgres/Supabase checkpointing** — sessions persist across restarts, and degrade gracefully to stateless mode if the DB URI isn't set.
>
> The whole thing runs on `docker compose up --build` with a single Groq API key.
>
